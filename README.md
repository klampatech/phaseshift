# Phase Shifter

A 3D voxel exploration game where you walk through three **phases** — Alpha, Beta, Gamma — and the world around you physically changes: blocks become solid in one phase, intangible in another. Built with Three.js + Vite. See [`GAME_SPEC.md`](./GAME_SPEC.md) for the design and [`PROJECT_REMEDIATION_PLAN.md`](./PROJECT_REMEDIATION_PLAN.md) for the current roadmap.

## Develop

```bash

npm run build     # produces dist/
npm run preview   # serves dist/ on :4173
```

## Test

```bash
# Headless smoke test (boots server + chromium, captures screenshots)
npm run build && node tests/headless/smoke.cjs

# safeOn unit test (no build needed)
node tests/headless/test-safeon.cjs
```

## Architecture

Single active code path:

```
index.html → main.js → src/core/{world,phase,physics}.js
                       src/render/renderer.js
                       src/{input,ui,audio,save}/*
```

The orphan `GameEngine` modules under `src/core/{game,player,phaseManager,phaseLockManager,particles}.js` are kept as **reference-only** for incremental feature ports; they are not imported by the active path. Each carries a `REFERENCE IMPLEMENTATION — DO NOT IMPORT` banner at the top.

See [`HANDOFF.md`](./HANDOFF.md) for a session-to-session handoff document covering the full layout, sandbox quirks, and the next phase's starting point.
